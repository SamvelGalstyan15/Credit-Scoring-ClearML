# 🚀 Credit Scoring with ClearML MLOps

### ⚙️ Статус проекта: 🚧 В процессе разработки (Work In Progress)

Этот проект является развитием базовой модели нейросети для кредитного скоринга. Здесь мы интегрируем **ClearML** для контроля версий данных, трекинга экспериментов и логирования метрик ROC AUC.
